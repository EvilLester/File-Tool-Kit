File-Tool-Kit

A fast, lightweight, and user-friendly file search and system cleanup tool for Windows.

🌟 Overview

File-Tool-Kit is designed to solve a common Windows problem: hard drives cluttering up with junk files, cache data, and unused logs that waste space and slow down system performance.

Instead of dealing with complicated menus, heavy software, or confusing interfaces, File-Tool-Kit gives you a clean search experience. You can quickly search for folders or games—like typing Steam or Xbox—and review or clean temporary files without headache.

✨ Key Features

🔍 Fast & Simple Search: Find files and directories without getting bogged down by slow search speeds.

🧹 Targeted System Cleaning: Quickly locate hidden temporary files, system crash dumps, and game caches (NVIDIA, AMD, DirectX).

🎮 Game & Launcher Cleanup: Easily locate leftover cache and log files from popular platforms like Steam, Epic Games, and Rockstar Games.

🛡️ Color-Coded Safety System:

🔴 Red (Remove): Temporary junk, logs, and cache files that are safe to delete.

🟡 Yellow (Review): Folders you should check before deleting to make sure you don't lose personal settings.

🟢 Green (Good): Essential files that are kept safe from accidental deletion.

🌙 Modern Dark Theme: Simple, dark UI designed for easy reading and fast actions.

🚀 Getting Started

Prerequisites

Windows OS

Python 3.x installed on your computer

Running the Application

Download or clone this repository:

git clone https://github.com/YourUsername/File-Tool-Kit.git


Navigate to the folder:

cd File-Tool-Kit


Run the application script:

python cleaner.py


🛠️ Usage

Start Scan: Click the scan button to automatically detect temporary junk across Windows and common game folders.

Review Items: Look through the listed locations, sizes, and explanations for why an item was flagged.

Open or Delete: Select a file or folder to open its location in Windows Explorer or remove it to free up disk space.
